# Практическая работа 1: RISC-V

Бостанджогло Максим Михайлович, группа **М3О-138СВ-26**.
Номер в списке группы: **3**.

Параметры варианта: `y = 138`, `h = 3`, `n = 3`, размер массива `16 + n = 19`.

## Программы

Каждый файл запускается отдельно в RARS в режиме RV32.
Числа вводятся по одному на строке; ввод и вывод используют системные вызовы RARS.

| Файл | Задание | Результат |
| --- | --- | --- |
| [task_a.asm](task_a.asm) | 3а | Читает `x`, выводит `1`, если `x = 3`, иначе `0`. |
| [task_b.asm](task_b.asm) | 3б | Читает `x`, выводит числа от `min(x, 138)` до `max(x, 138)` с шагом `3`. |
| [task_c.asm](task_c.asm) | 3в | Заполняет массив максимум из 19 чисел; останавливается при вводе `0` или заполнении массива. |

В задании 3б верхняя граница выводится только тогда, когда до неё можно дойти
от нижней границы с шагом 3. Например, при `x = 134` вывод: `134 137`.

В задании 3в ноль является признаком конца ввода и не записывается в массив.
После чтения программа выводит сохранённые элементы, чтобы результат было видно.
В памяти RARS они доступны по метке `array`, их количество хранится по метке `count`.
Неиспользованная часть массива остаётся нулевой.

## Запуск в окне RARS

На этом компьютере RARS и Java установлены локально в папке `tools`.
Открыть симулятор можно двойным нажатием на **RARS.command** или командой:

```sh
./RARS.command
```

В RARS: **File → Open** и выбрать один файл `.asm`, затем **Run → Assemble** (F3)
и **Run → Go** (F5). Вводить числа в панели **Run I/O**.
Для повторного запуска использовать **Run → Reset**.
Опция **Settings → Assemble all files in directory** должна быть выключена:
это три самостоятельные программы с отдельными метками `main`.

## Установка на другом компьютере

Нужна Java 8 или новее и [RARS 1.6](https://github.com/TheThirdOne/rars/releases/tag/v1.6).
Скачать файл `rars1_6.jar` из официального релиза и поместить в `tools/rars.jar`.
Java можно получить на [сайте Eclipse Temurin](https://adoptium.net/).
На macOS и Linux после клонирования выполнить:

```sh
chmod +x RARS.command tools/rars.sh
./RARS.command
```

На Windows: `java -jar tools/rars.jar`.
Java и файл симулятора не входят в Git-репозиторий.

## Проверка

```sh
python3 tests/check.py
```

Проверки выполняют программы в самом RARS: сравнение номера, оба порядка границ,
несовпадение верхней границы с шагом, отрицательные значения, остановку по нулю,
заполнение 19 элементов и отказ от чтения двадцатого элемента.

Описание системных вызовов: [RARS Environment Calls](https://github.com/TheThirdOne/rars/wiki/Environment-Calls).
Формат запуска из терминала: [RARS command line](https://github.com/TheThirdOne/rars/wiki/Using-the-command-line).
Для ознакомления с форматом работы использован
[пример Андрея Беликова](https://github.com/yourgfslove/homework_CS_1).
